# Proposal: ให้หน้าโหมดปรับปรุงมีเนื้อหาจริง (กัน SEO ตกระหว่างปิดยาว 4 เดือน)

## Why

เจ้าของเว็บจะ **เปิดโหมดปรับปรุงต่อเนื่องประมาณ 4 เดือน** แล้วหลังจากนั้นจะไม่ใช้อีก
ความต้องการทางธุรกิจคือ **ยังไม่อยากให้ลูกค้าติดต่อเข้ามาในช่วงนั้น** ส่วนความกังวล
คือ **พอกดปิดโหมดแล้วอันดับใน Google จะตก**

### สิ่งที่ตรวจแล้วว่า "ไม่ใช่ปัญหา" — จะได้ไม่แก้ผิดจุด

| สิ่งที่ Google ใช้จัดอันดับ | สถานะตอนเปิดโหมดปรับปรุง |
|---|---|
| หน้าสินค้า `/showcase/*` (ตัวที่ติดอันดับจริง) | ✅ เปิดปกติ ไม่ถูกบล็อก |
| `/catalog`, `/about`, `/document/*` | ✅ เปิดปกติ |
| `sitemap.xml` | ✅ ประกาศ URL ครบ ไม่เช็คโหมดปรับปรุง |
| JSON-LD (Organization, ที่อยู่, เบอร์โทร, ItemList สินค้า) | ✅ ยังส่งให้ Google ครบ |

**การซ่อนเบอร์โทร/LINE ไม่กระทบอันดับ** — Google ไม่ได้ลดอันดับเพราะเว็บไม่แสดง
ช่องทางติดต่อ ดังนั้นความต้องการ "ไม่อยากให้ลูกค้าติดต่อ" กับ "SEO ไม่ตก"
**ไม่ได้ขัดกันเลย** และ change นี้จะไม่แตะการซ่อนข้อมูลติดต่อ

### ปัญหาจริงมีข้อเดียว

`MaintenanceOverlay` แสดงแค่รูปเฟืองหมุนกับข้อความขอโทษ — **ไม่มีคำที่บอกว่า
ธุรกิจนี้ทำอะไรเลยสักคำ** ไม่มี "เครื่องมือวัด" "สอบเทียบ" "ห้องปฏิบัติการ"

overlay เป็น element พี่น้องของ `{children}` (`app/layout.tsx`) ไม่ได้แทนที่เนื้อหา
— เนื้อหาจริงยังอยู่ใน HTML แค่ถูก CSS บังไว้ แต่ overlay มี `<h1>` ของตัวเอง
(`เว็บไซต์อยู่ระหว่างปรับปรุง`) ทำให้หน้าแรกมี `<h1>` สองตัวที่สื่อคนละเรื่อง และ
ข้อความนี้เพิ่งเข้าไปอยู่ใน HTML ฝั่ง server เมื่อ change ก่อนหน้า
(ย้ายจาก client fetch มา server render เพื่อกำจัด flash)

**ที่ 4 เดือน** Google จะมาเก็บหน้าแรกนับสิบครั้ง สิ่งที่มันเห็นซ้ำๆ จะกลายเป็น
ความจริงในสายตามัน — หน้าแรกจะค่อยๆ ขาดความเชื่อมโยงกับธุรกิจ

## What Changes

เปลี่ยน **เฉพาะเนื้อหาภายใน** `MaintenanceOverlay` จาก "ฉากเปล่า" เป็นหน้าที่
มีสาระ โดย **ไม่แตะกลไกเปิด-ปิดแม้แต่บรรทัดเดียว**

### ทำไมการแก้นี้ปลอดภัยต่อการกดปิดโหมด

ด่านตัดสินใจอยู่ก่อนเนื้อหาเสมอ:

```
if (isLoggedIn) return null;                    // แอดมินผ่าน
if (!ใช่หน้าที่บล็อก) return null;                // หน้าอื่นผ่าน
if (!enabled) return null;                      // ◀ ปิดโหมด = จบตรงนี้
return ( ...เนื้อหาที่ change นี้แก้... )          // ไปไม่ถึง
```

เรากำลังแก้ป้ายที่แขวนอยู่หลังประตู ไม่ได้แก้ตัวประตู ปิดโหมด = ประตูเปิด
ป้ายหายไปพร้อมกัน ส่วนข้อมูลติดต่อกลับมาจาก `Footer` ซึ่งเป็นคนละ component
คนละไฟล์ ตัดสินจาก `maintenanceOn && !isLoggedIn` เท่านั้น

### เนื้อหาที่จะใส่ — มาจากสิ่งที่เว็บประกาศไว้จริง ไม่ได้แต่งใหม่

ทุกข้อความดึงจากค่าที่มีอยู่ในโค้ดแล้ว เพื่อไม่ให้มีการกล่าวอ้างเรื่องธุรกิจ
ที่ไม่มีใครตรวจสอบ และเพื่อไม่ให้ข้อความสองที่หลุดจากกันเมื่อมีการแก้ในอนาคต:

| ส่วน | แหล่ง |
|---|---|
| ชื่อบริษัท | `SITE_LEGAL_NAME`, `SITE_NAME` (`app/lib/site.ts`) |
| บอกว่าทำอะไร | กลุ่มบริการใน `hasOfferCatalog` ของ `ProductsJsonLd.tsx` |
| ลิงก์หน้าที่ยังเปิด | `/catalog` (ยังเข้าได้ระหว่างโหมดปรับปรุง) |

**ไม่ใส่:** เบอร์โทร, LINE, อีเมล, ฟอร์มติดต่อ — ตรงตามความต้องการ และไม่กระทบอันดับ

### จุดที่ต้องตัดสินใจ

1. **ไม่ระบุวันที่กลับมา** — วันที่ที่ hardcode ไว้ต้องแก้โค้ดเพื่ออัปเดต และถ้า
   เลื่อนก็จะกลายเป็นข้อมูลผิดค้างอยู่บนหน้าสาธารณะ เขียนกว้างๆ ปลอดภัยกว่า
2. **ใส่ลิงก์ไป `/catalog`** — ช่วยให้ Google เดินจากหน้าแรก (หน้าที่มี authority
   สูงสุด) ไปยังหน้าที่ยังเปิดอยู่ ถ้าไม่มีลิงก์เลย authority นั้นไม่ไหลไปไหน
   **ไม่ขัดกับความต้องการ** เพราะ `/catalog` เปิดสาธารณะอยู่แล้วและอยู่ใน sitemap
   — ลิงก์แค่ทำให้เส้นทางที่มีอยู่แล้วมองเห็นได้ ไม่ได้เปิดช่องติดต่อใหม่
   ถ้าไม่ต้องการให้ลูกค้าคลิกต่อ ตัดบล็อกลิงก์ออกได้โดยไม่กระทบส่วนอื่น

## ที่ไม่ทำใน change นี้

- **ไม่ตอบ HTTP 503** — เหมาะกับหน่วยชั่วโมงถึงไม่กี่วัน ถ้าตอบติดกัน 4 เดือน
  Google จะเลิกเชื่อว่าชั่วคราวแล้วถอดหน้าออกอยู่ดี แถมการจะรู้ว่าผู้เรียกไม่ใช่
  แอดมินต้องอ่าน cookie ซึ่งจะบังคับให้ `/` และ `/contact` กลายเป็น dynamic
  (เสีย ISR/static)
- **ไม่ใส่ `noindex`** — ให้ผลตรงข้ามกับที่ต้องการ: มันสั่งถอดหน้าออกจาก index จริง
  พอปิดโหมดต้องรอให้ Google กลับมาเก็บและจัดอันดับใหม่ แย่กว่าไม่ทำอะไร
- **ไม่แตะการซ่อนข้อมูลติดต่อใน `Footer`** — เป็นความต้องการทางธุรกิจ และไม่ใช่
  สาเหตุของปัญหา SEO
- **ไม่แตะ `MAINTENANCE_BLOCKED_PATHS`** — หน้าสินค้าที่ทำอันดับจริงต้องเปิดต่อไป
- **ไม่แก้ schema** — `SCHEMA_VERSION` ต้องอยู่ที่ 41 เท่าเดิม

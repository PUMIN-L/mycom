# Proposal: เพิ่มดาวน์โหลด Excel ให้เอกสารที่ตอนนี้มีแค่ PDF

## Why

หลังจากเพิ่มปุ่ม "ดาวน์โหลด Excel" ให้ใบสั่งซื้อ (PO) ไปแล้ว เจ้าของระบบขอให้
เพิ่มแบบเดียวกันให้ **เอกสารอื่นที่ยังมีแค่ปุ่มดาวน์โหลด PDF อย่างเดียว**

ตรวจทั้งระบบแล้ว (`grep` หาไฟล์ที่มี `generatePdf`/`html2canvas-pro`/ปุ่ม
"ดาวน์โหลด PDF") พบ 3 หน้าที่เป็นเป้าหมายจริง (ไม่นับ
`app/tools/pdf-editor` ซึ่งเป็นเครื่องมือแก้ไข PDF ทั่วไปที่อัปโหลดไฟล์อะไร
ก็ได้ ไม่มีข้อมูลโครงสร้างให้ export เป็นตารางได้):

1. **`app/quotation/page.tsx`** — ใบเสนอราคา
2. **`app/billing/page.tsx`** — เอกสารบัญชี (ใบแจ้งหนี้/ใบวางบิล/ใบเสร็จ —
   3 ประเภทในไฟล์เดียว, สลับด้วย `docType`)
3. **`app/service-job/page.tsx`** — ใบ Job บริการหน้างาน

ทั้งสามหน้าไม่มีปุ่ม Excel เลย มีแค่ "⬇️ ดาวน์โหลด PDF" (client-side
html2canvas+jsPDF) เพียงอย่างเดียว

## What Changes

**อัปเดตหลังทำจริง**: ตัวอย่างแรกที่ทำ (Excel ของ PO แบบ 2 ชีท label–value)
ถูกเจ้าของระบบปฏิเสธหลังเห็นไฟล์จริง ("excel ไม่เอาแบบนี้ ให้เป็นแบบ form
แบบจำลอง PDF และสามารถเซฟเป็น pdf ได้เลย") จึงเปลี่ยนกลไกกลางเป็นชีทเดียว
ที่จัดหน้าให้ใกล้เคียง PDF จริง (หัวเรื่อง/คู่กรณี/ตารางรายการมีเส้นขอบและสี
พื้นหัวตาราง/สรุปยอด/ลายเซ็น) แทนตาราง label–value 2 ชีทแบบเรียบๆ — ใช้
ตัวช่วยกลางใหม่ `buildDocumentFormSheet()`/`downloadDocumentFormExcel()` ใน
`app/lib/documentFormExcel.ts` (สร้างสไตล์เซลล์ด้วย `xlsx-js-style` ซึ่งเป็น
fork ของ `xlsx` ที่คง API เดิมแต่คืนความสามารถใส่ style ที่ `xlsx` ตัดออก) —
**ไม่แก้ `app/lib/xlsxExport.ts` เดิมเลย** ไฟล์นั้นยังใช้กับ export ข้อมูลแบบ
รายการล้วน (ลูกค้า/อุปกรณ์/รายงาน) เหมือนเดิมทุกจุด เพิ่มแค่ปุ่ม "📊 ดาวน์โหลด
Excel" ข้างปุ่ม PDF เดิมในแต่ละหน้า **ไม่แตะโค้ด PDF/บันทึก/เลขที่เอกสารเดิม
เลยแม้แต่บรรทัดเดียว** — เป็นการเพิ่มความสามารถล้วนๆ ไม่ใช่การแก้ของเดิม

ไฟล์ `.xlsx` ที่ได้ไม่ใช่ PDF โดยตัวมันเอง (ไฟล์ฟอร์แมตนี้ทำแบบนั้นไม่ได้) —
สิ่งที่ทำได้คือจัดหน้าให้ใกล้เคียง PDF ที่สุดเท่าที่สเปรดชีตจะทำได้ ผู้ใช้กด
Save as PDF / Print → Save as PDF ของ Excel/Numbers เองอีกทีเพื่อได้ไฟล์ PDF
จากชีทนี้

โครงร่างชีทเดียวที่ใช้ร่วมกันทั้ง 4 เอกสาร (PO + 3 เอกสารในงานนี้): หัวเรื่อง
เอกสาร (กลาง, ตัวหนา) → ข้อมูลคู่กรณีสองฝ่าย (เรา/อีกฝ่าย) → ข้อมูลเอกสาร
(เลขที่/วันที่/ฯลฯ) → ตารางรายการ (มีเส้นขอบ, หัวตารางพื้นสีเข้มตัวอักษรขาว)
→ สรุปยอด (เฉพาะเอกสารที่มีมูลค่าเงิน, แถวยอดสุทธิหนา+มีเส้นคั่น) → หมายเหตุ/
เงื่อนไข → แถวลงลายเซ็น

### 1. ใบเสนอราคา (`app/quotation/page.tsx`)
1 ชีท "ใบเสนอราคา": หัวเรื่อง → ผู้เสนอราคา (เรา)/ลูกค้า → เลขที่/วันที่/ยืน
ราคากี่วัน → ตารางรายการ (ลำดับ/รายการ/จำนวน/หน่วย/ราคาต่อหน่วย/ส่วนลด
ถ้ามี/จำนวนเงิน) → สรุปยอด (ก่อนภาษี/VAT 7%/สุทธิ) → เงื่อนไข (การชำระเงิน/
ส่งมอบ/รับประกัน) เป็นหมายเหตุ → ลายเซ็น 3 ช่อง (ผู้เสนอราคา/ผู้อนุมัติ/
ลูกค้า)

### 2. เอกสารบัญชี (`app/billing/page.tsx`)
1 ชีทเหมือนใบเสนอราคาทุกจุด (`items`/`computeQuoteTotals` ตัวเดียวกัน) แต่:
- หัวเรื่อง/ชื่อชีทปรับตามประเภทเอกสารที่เลือกอยู่ ("ใบแจ้งหนี้ / ใบกำกับ
  ภาษี" / "ใบวางบิล" / "ใบเสร็จรับเงิน" — ใช้ `BILLING_LABELS` ที่มีอยู่แล้ว
  ใน `billingNumber.ts`)
- **ใบเสร็จ** เพิ่มบล็อกหมายเหตุช่องทางชำระเงิน/วันที่ชำระ/เลขที่อ้างอิง
  (ตรงกับที่พิมพ์บนสลิปอยู่แล้วตอนเป็นใบเสร็จ) — ประเภทอื่นไม่มี 3 รายการนี้
- ลายเซ็น: ใบเสร็จใช้ "ผู้รับเงิน/ผู้จ่ายเงิน", ประเภทอื่นใช้ "ผู้ออกเอกสาร/
  ผู้อนุมัติ"

### 3. ใบ Job บริการ (`app/service-job/page.tsx`)
**โครงสร้างต่างจากสองอันบนโดยสิ้นเชิง — ไม่ใช่เอกสารการเงิน ไม่มี
`computeQuoteTotals` เลย** ใช้ชีทเดียวกันแบบเดียวกับ PO/ใบเสนอราคา/บัญชี
แต่ข้าม**บล็อกสรุปยอด**ไปทั้งหมด (`totals` เป็น `undefined`):
หัวเรื่อง → ผู้ให้บริการ (เรา)/ลูกค้า → เลขที่เอกสาร/วันที่เข้าบริการ/ช่าง
ผู้ปฏิบัติงาน → ตารางเครื่องที่เข้าบริการ (ลำดับ/ชื่อเครื่อง/หมายเลขเครื่อง/
งานที่ทำ — คอลัมน์ "งานที่ทำ" เว้นว่างตรงกับ PDF ที่เว้นไว้ให้ช่างเขียนด้วย
มือหน้างาน ไม่ใช่ข้อมูลที่หายไป) → หมายเหตุอธิบายว่ารายละเอียดงานเขียนด้วย
ลายมือในต้นฉบับที่พิมพ์ → ลายเซ็น 1 ช่อง ("ลูกค้าผู้รับบริการ" — ตรงกับที่
เอกสารจริงมีลายเซ็นเดียว) เอกสารนี้ยังต้องบันทึก (มินต์เลขที่) ก่อนถึงจะ
ดาวน์โหลด Excel ได้ ตามกติกาเดียวกับปุ่มดาวน์โหลด PDF ("ยังไม่มีเลขที่ใบงาน
กรุณากดบันทึกก่อนดาวน์โหลด")

## Impact

- Affected specs: `document-export` (capability ใหม่ — ครอบคลุมทั้ง 3 หน้า
  ในการเปลี่ยนเดียว เพราะเป็นความสามารถเดียวกันที่ขยายไปหลายจุด)
- Affected code:
  - แก้ (เพิ่มปุ่ม+ฟังก์ชัน export เท่านั้น ไม่แตะของเดิม):
    `app/quotation/page.tsx`, `app/billing/page.tsx`,
    `app/service-job/page.tsx`
  - ใช้ร่วม (สร้างใหม่ในงานนี้ ใช้ร่วมกับ PO ด้วย): `app/lib/documentFormExcel.ts`
  - dependency ใหม่: `xlsx-js-style` (client-side only, dynamic import)
  - ใช้ซ้ำโดยไม่แก้: `app/lib/xlsxExport.ts` (`sanitizeExcelCell` เท่านั้น),
    `app/lib/billingNumber.ts` (`BILLING_LABELS` — read-only import)
- ไม่กระทบ: การบันทึก, การมินต์เลขที่เอกสาร, การสร้าง PDF, DB schema (ไม่มี
  การเปลี่ยนแปลงฐานข้อมูลเลยในงานนี้)
- `app/purchase-order/page.tsx`: Excel export ของ PO (ทำเสร็จไปแล้วในงาน
  ก่อนหน้าด้วยดีไซน์ 2 ชีท flat) ถูกเปลี่ยนมาใช้ `documentFormExcel.ts`
  เดียวกันนี้ด้วย เพื่อให้ทั้ง 4 เอกสารหน้าตาสอดคล้องกัน — ดูรายละเอียดใน
  `openspec/changes/add-purchase-order/specs/purchase-order/spec.md`

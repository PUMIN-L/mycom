# Proposal: ทะเบียนทรัพย์สินบริษัท + สต็อกสินค้า (admin เท่านั้น)

## Why

บริษัทยังไม่มีที่บันทึกว่า "ของชิ้นนี้ซื้อเข้ามาเมื่อไหร่ ราคาเท่าไหร่ อยู่ที่ไหน
สถานะเป็นยังไง" — ทั้งของที่ซื้อมาใช้เอง (คอมพิวเตอร์ เครื่องมือ เฟอร์นิเจอร์)
และของที่ซื้อมาเพื่อขายต่อ ตอนนี้ต้องจำเอาเองหรือจดแยกใน Excel ทำให้ตอบคำถาม
ง่ายๆ ไม่ได้ เช่น "เครื่องชั่งรุ่นนี้เหลือพร้อมขายกี่เครื่อง", "ใครยืมเครื่องนี้ไป
กำหนดคืนเมื่อไหร่", "ของที่ยังมีอยู่มูลค่ารวมเท่าไหร่"

## What changes

สองหน้าใหม่ สำหรับ admin ที่ login แล้วเท่านั้น ใช้ได้ทั้งบนคอมและมือถือ
(ต่างจากหน้า admin อื่นที่ตกลงกันว่าทำแค่บนคอม — สองหน้านี้ต้องเดินเช็คของ
ในคลังด้วยมือถือได้ และเปิดจาก QR บนสติกเกอร์):

- `/assets` — **ทรัพย์สินบริษัท** (ของที่ซื้อมาใช้เอง)
- `/stock` — **สต็อกสินค้า** (ของที่ซื้อมาเพื่อขายต่อ)

ทั้งสองหน้าใช้โครงเดียวกัน:

1. **รายการ + ชิ้น** — "รายการ" คือของรุ่นหนึ่ง (ชื่อ/ยี่ห้อ/รุ่น/หมวด)
   "ชิ้น" คือของแต่ละตัว มีรหัส ซีเรียล วันที่ซื้อ ราคา ผู้ขาย ที่เก็บ สถานะ
   ของตัวเอง ระบบนับจำนวนชิ้นต่อรายการ แยกตามสถานะให้เอง
2. **รหัสอัตโนมัติต่อชิ้น** `AS-0001` (ทรัพย์สิน) / `ST-0001` (สต็อก) ไม่ซ้ำ
   และไม่นำกลับมาใช้แม้ลบชิ้นไปแล้ว
3. **สถานะเลือกจากรายการ** (คนละชุดต่อหน้า) บางสถานะมีช่องกรอกเพิ่ม
   (ผู้ยืม + กำหนดคืน, ส่งซ่อมที่, จองให้, วันที่ขาย + ขายให้, วันที่จำหน่าย)
4. **ประวัติต่อชิ้น** — ทุกครั้งที่เปลี่ยนสถานะ ย้ายที่เก็บ หรือย้ายรายการ
   ระบบจดลงไทม์ไลน์ของชิ้นนั้นเอง แก้ไขไม่ได้
5. **ผู้ขาย** — เลือกจากรายชื่อ Suppliers หรือพิมพ์เองก็ได้ ในช่องเดียว
6. **ที่เก็บ / หมวด** — พิมพ์เองได้ ระบบเสนอค่าที่เคยใช้แล้วให้เลือก
7. **ช่องค้นหา + ตัวกรอง** (สถานะ หมวด ที่เก็บ ผู้ขาย ช่วงวันที่ซื้อ) ซ่อนของที่
   ออกไปแล้วโดยค่าเริ่มต้น มูลค่ารวมนับเฉพาะของที่ยังมีอยู่
8. **เพิ่มทีละหลายชิ้น** (สูงสุด 100 ต่อครั้ง) **เปลี่ยนสถานะ/ที่เก็บทีละหลาย
   ชิ้น**, ย้ายชิ้นไปรายการอื่น, รวมรายการที่สร้างซ้ำ
9. **ส่งออก Excel** (2 ชีต: รายชิ้น + สรุปต่อรายการ) ตามที่ค้นหา/กรองอยู่
10. **พิมพ์สติกเกอร์** (ไม่บังคับ) — QR + รหัส + ชื่อ/รุ่น หลายขนาดกระดาษให้
    เลือก สแกน QR แล้วเปิดหน้าของชิ้นนั้น

## จุดตัดสินใจที่ตกลงกับเจ้าของระบบแล้ว

- แยกสองหน้า (ทรัพย์สิน / สต็อก) — ผู้ใช้เห็นเป็นคนละฟังก์ชัน
- 1 ชิ้น = 1 แถว แต่จัดเป็น "รายการ + ชิ้น" ให้ระบบนับให้
- สถานะเลือกจากรายการ, ที่เก็บพิมพ์เองพร้อมคำแนะนำ
- ผู้ขาย: เลือกจาก Suppliers หรือพิมพ์เอง
- มีช่องตามสถานะ + ประวัติต่อชิ้น
- ส่งออก Excel, พิมพ์สติกเกอร์ (ไม่บังคับใช้)
- ใช้บนมือถือได้

## ไม่รวมในงานนี้

ค่าเสื่อมราคา · ผูกกับใบสั่งซื้อ (PO) · ผูกกับลูกค้า/แท็บอุปกรณ์ลูกค้า ·
ลงรายจ่าย (`/expenses`) อัตโนมัติ · ราคาขาย · แจ้งเตือนในกระดิ่ง · นำเข้า
จาก Excel · ตรวจนับ · ประวัติการแก้ไขทุกช่อง (มีแค่ไทม์ไลน์สถานะ/ที่เก็บ/รายการ)

## Impact

- DB: ตารางใหม่ 4 ตาราง (`inventory_groups`, `inventory_items`,
  `inventory_events`, `inventory_counters`) — `SCHEMA_VERSION` 46 → 47
- API ใหม่ `/api/admin/inventory/[kind]/**` (ต้อง login ทุก route)
- หน้าใหม่ `/assets/**`, `/stock/**` — เพิ่มใน `proxy.ts` matcher,
  `robots.ts` disallow, รายการหน้า admin ของ `GlobalAdminBell`, การ์ดใน
  `/adminpanel`
- ไม่แตะตารางหรือหน้าเดิม (ตาราง `suppliers` ถูกอ่านอย่างเดียว)

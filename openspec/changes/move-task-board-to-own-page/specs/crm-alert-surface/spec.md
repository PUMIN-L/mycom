# Spec Delta: crm-alert-surface

## ADDED Requirements

### Requirement: `/crm/alerts` ต้องมีทางไปหน้ากระดานงาน "สิ่งที่ต้องทำ"
เมื่อกระดานงานย้ายไปเป็นหน้าของตัวเอง (`/crm/tasks`, spec:
`move-task-board-to-own-page`) หน้า `/crm/alerts` SHALL แสดงปุ่ม/การ์ดลิงก์
ไปยัง `/crm/tasks` ในตำแหน่งเดิมที่บล็อกกระดานงานเคยอยู่ (ท้ายฟีดแจ้งเตือน
อัตโนมัติ) เพื่อให้ยังหาทางไปกระดานงานได้ในคลิกเดียวเหมือนก่อนย้าย ปุ่มนี้
SHALL:
- แสดงตัวเลข **จำนวนงานที่ถึงกำหนดแล้ว** (`dueTaskCount` จาก
  `/api/admin/alerts` ตัวเดียวกับที่กระดิ่งใช้) เป็น badge บนปุ่ม **เฉพาะเมื่อ
  มากกว่า 0** — SHALL ไม่ยิง request ใหม่ไปหาตัวเลขนี้อีกครั้ง (ใช้ค่าที่หน้า
  โหลดมาแล้วสำหรับแท็บอื่นอยู่แล้ว)
- SHALL ไม่แสดง badge ใดๆ เมื่อ `dueTaskCount` เป็น 0 หรือยังโหลดไม่เสร็จ
  (`null`) — เลข 0 ปลอมๆ อาจถูกเข้าใจผิดว่าไม่มีงานค้างทั้งที่จริงยังไม่รู้

#### Scenario: มีงานถึงกำหนดแล้ว
- **WHEN** `/api/admin/alerts` คืน `dueTaskCount: 4`
- **THEN** ปุ่ม "ไปที่หน้าสิ่งที่ต้องทำ" แสดง badge เลข 4 และลิงก์ไป
  `/crm/tasks`

#### Scenario: ไม่มีงานถึงกำหนด
- **WHEN** `/api/admin/alerts` คืน `dueTaskCount: 0`
- **THEN** ปุ่มยังลิงก์ไป `/crm/tasks` ได้ปกติ แต่ไม่มี badge ตัวเลขแสดงอยู่

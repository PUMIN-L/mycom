- [x] 1.1 นำชื่อบริษัทมาจาก `SITE_LEGAL_NAME` / `SITE_NAME` ไม่พิมพ์ซ้ำเป็น literal

      ติดตั้งและสอนการใช้งาน, ออกแบบและสร้างห้องปฏิบัติการ) อ้างอิงกลุ่มบริการ
      เดียวกับที่ `ProductsJsonLd` ประกาศ
- [x] 1.3 ใส่ลิงก์ไป `/catalog` (หน้าที่ยังเปิดระหว่างโหมดปรับปรุง)

- [x] 1.5 ไม่ระบุวันที่กลับมาแบบ hardcode

## 2. โครงสร้าง heading
- [x] 2.1 ลด `<h1>` ของ overlay ลงเป็น `<p>` หรือ `<h2>` เพื่อไม่ให้ชนกับ `<h1>`
      ของหน้าจริงที่อยู่ข้างใต้ (Hero บนหน้าแรก) — overlay เป็น element พี่น้อง
      ไม่ได้แทนที่เนื้อหา ทั้งคู่จึงอยู่ใน HTML พร้อมกัน
